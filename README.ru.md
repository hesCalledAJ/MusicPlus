## 📱 Установка

Music + — это **плагин для exteraGram**, поэтому сначала нужен exteraGram. Настройте его один раз, а затем установите Music + меньше чем за минуту.

### Шаг 1 — Настройте exteraGram

> [!NOTE]
> exteraGram — клиент Telegram для **Android**. Версий для iOS и компьютера нет.

1. **Скачайте exteraGram** из одного из официальных источников:
   - [exteragram.app](https://exteragram.app)
   - [@exteraGram](https://t.me/exteraGram) (новости и обновления)
   - [@exteraReleases](https://t.me/exteraReleases) (APK-файлы)
2. **Установите APK.**
3. **Войдите** в свой аккаунт Telegram так же, как в обычном приложении.
4. **Включите плагины.** Откройте exteraGram **Настройки → Плагины** и включите движок плагинов.
5. **Проверьте версию.** Для Music + нужен exteraGram `12.10.6` или новее. Если у вас более старая версия, обновите приложение.

> [!NOTE]
> Возможно, перед установкой APK Android потребует разрешить установку из **неизвестных источников**. [Как это включить](https://t.me/exteraSettings?s=pluginsUnknownSources).
>
> Не хотите включать? Можно [установить из известного источника](https://t.me/exteraPluginsSup/1196). Обновления там приходят позже, чем в официальных каналах.

### Шаг 2 — Установите Music +

Выберите удобный способ.

#### Вариант А — Через каталог плагинов в Telegram (рекомендуется)

1. **[Добавьте плагины AJ как репозиторий плагинов](https://t.me/exteraPluginRepo?c=AJ_Plugins)** в exteraGram/AyuGram.
2. Найдите **Music +** и нажмите **Установить**.
3. Включите плагин.

#### Вариант Б — Ручная установка с GitHub

1. Откройте [последний релиз](https://github.com/hesCalledAJ/MusicPlus/releases/latest).
2. Скачайте файл `MusicPlus-vX.Y.elyx`, прикреплённый к релизу.
3. Отправьте файл в любой чат (удобно — в «Избранное») и нажмите на него, чтобы установить.
4. Подтвердите установку и включите Music +.

> [!TIP]
> По умолчанию Music + заменяет встроенный экран музыкального плеера Telegram. Включите **вкладку Music** в настройках плагина, чтобы получить полный интерфейс медиатеки.

| Компонент | Минимум |

## 🤝 Участие в разработке

Мы рады любому вкладу: сообщению об ошибке, переводу или изменению кода.

### Сообщить об ошибке или предложить функцию

Создайте [issue](https://github.com/hesCalledAJ/MusicPlus/issues) и укажите:

- что вы ожидали и что произошло на самом деле;
- версии exteraGram и Music +;
- шаги для воспроизведения и, если это поможет, скриншот.

### Добавить или исправить перевод

1. Сделайте форк репозитория.
2. Измените файл своего языка в `MusicPlus/strings/` (`strings_en.yml`, `strings_fa.yml` или `strings_ru.yml`). Для нового языка скопируйте `strings_en.yml` и переведите его.
3. Откройте pull request.

### Предложить изменение кода

1. Сделайте форк репозитория и создайте ветку.
2. Внесите изменения в `MusicPlus/`.
3. [Соберите проект локально](#-для-разработчиков) и проверьте его в exteraGram.
4. Откройте pull request с описанием того, что и зачем вы изменили.

Пожалуйста, не меняйте `version` в `MusicPlus/metainfo.yml` и не редактируйте `extera-plugins.json` в pull request. Они обновляются при публикации релиза.

## 🧩 Для разработчиков

### Локальная сборка

```bash
python -m pip install pyyaml
python scripts/build_elyx.py
```

Скрипт проверяет синтаксис Python и создаёт `dist/MusicPlus-vX.Y.elyx`. Установите этот файл так же, как в [Варианте Б](#вариант-б--ручная-установка-с-github).

### Публикация релиза (для мейнтейнеров)

1. Обновите `version` в `MusicPlus/metainfo.yml` и отправьте изменения.
2. Создайте релиз на GitHub с соответствующим тегом и префиксом `v` (версия `1.6` → тег `v1.6`).

Остальное делает workflow `release.yml`: собирает `.elyx`, прикрепляет его к релизу и обновляет `extera-plugins.json` (ссылка для загрузки, SHA-256 и размер).

Для компилируемых сборок см. [официальную документацию ElyxBuilder](https://plugins.exteragram.app/docs/elyx/elyxbuilder).
