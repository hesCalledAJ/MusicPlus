## 📱 نصب

‏Music +‎ یک **افزونه برای exteraGram** است، پس ابتدا به exteraGram نیاز دارید. یک بار آن را راه‌اندازی کنید و بعد Music +‎ را در کمتر از یک دقیقه نصب کنید.

### مرحلهٔ ۱ — راه‌اندازی exteraGram

> [!NOTE]
> ‏exteraGram یک کلاینت تلگرام برای **اندروید** است. نسخهٔ iOS یا دسکتاپ ندارد.

1. ‏**exteraGram را دانلود کنید** از یکی از منابع رسمی:
   - [exteragram.app](https://exteragram.app)
   - [@exteraGram](https://t.me/exteraGram) (اخبار و به‌روزرسانی‌ها)
   - [@exteraReleases](https://t.me/exteraReleases) (فایل‌های APK)
2. **فایل APK را نصب کنید.**
3. **وارد حساب تلگرام خود شوید**، درست مثل برنامهٔ معمولی.
4. **افزونه‌ها را فعال کنید.** به **تنظیمات exteraGram ← افزونه‌ها (Plugins)** بروید و موتور افزونه‌ها را روشن کنید.
5. **نسخه را بررسی کنید.** Music +‎ به exteraGram نسخهٔ `12.10.6` یا جدیدتر نیاز دارد. اگر نسخهٔ شما قدیمی‌تر است، برنامه را به‌روزرسانی کنید.

> [!NOTE]
> ممکن است پیش از نصب APK لازم باشد اندروید را برای نصب از **منابع ناشناس (Unknown Sources)** مجاز کنید. [روش فعال‌سازی](https://t.me/exteraSettings?s=pluginsUnknownSources).
>
> نمی‌خواهید آن را فعال کنید؟ می‌توانید [از یک منبع شناخته‌شده نصب کنید](https://t.me/exteraPluginsSup/1196). به‌روزرسانی‌ها در آنجا دیرتر از کانال‌های رسمی می‌رسند.

### مرحلهٔ ۲ — نصب Music +‎

هر روشی را که راحت‌تر است انتخاب کنید.

#### روش الف — از کاتالوگ افزونه‌های تلگرام (پیشنهادی)

1. **[این کانال را بعنوان مخزن افزونه (Plugin Repository) اضافه کنید](https://t.me/exteraPluginRepo?c=AJ_Plugins)** در exteraGram یا AyuGram.
2. ‏**Music +‎** را پیدا کنید و روی **نصب** بزنید.
3. افزونه را فعال کنید.

#### روش ب — نصب دستی از GitHub

1. [آخرین نسخه (Release)](https://github.com/hesCalledAJ/MusicPlus/releases/latest) را باز کنید.
2. فایل `MusicPlus-vX.Y.elyx` پیوست‌شده به آن را دانلود کنید.
3. فایل را در هر چتی بفرستید (پیام‌های ذخیره‌شده گزینهٔ خوبی است) و برای نصب روی آن بزنید.
4. نصب را تأیید کنید و Music +‎ را فعال کنید.

> [!TIP]
> به‌طور پیش‌فرض Music +‎ جایگزین صفحهٔ پخش‌کنندهٔ داخلی تلگرام می‌شود. برای دسترسی به رابط کامل کتابخانه، **تب Music** را در تنظیمات افزونه فعال کنید.

## 🗂️ ساختار پروژه

```text
.
├── .github/
│   └── workflows/
│       └── release.yml              # Builds, attaches and indexes each release
├── assets/
│   └── musicplus-banner.png         # Repository banner
├── MusicPlus/                       # Unpacked Elyx project (source of truth)
│   ├── refmap.yml                   # Elyx entry-point and resource map
│   ├── metainfo.yml                 # Plugin metadata and version
│   ├── strings/
│   │   ├── strings_en.yml           # English
│   │   ├── strings_fa.yml           # Persian
│   │   └── strings_ru.yml           # Russian
│   └── musicplus/
│       ├── main.py                  # Main player / queue integration
│       ├── tabs.py                  # Music tab integration
│       ├── sheets.py                # Player and library sheets
│       ├── editor/                  # Library, header and playback editors
│       ├── features/                # Playlists, sync, downloads and playback
│       └── ...                      # Supporting modules
├── scripts/
│   ├── build_elyx.py                # Creates dist/MusicPlus-vX.Y.elyx
│   └── update_index.py              # Writes release URL, SHA-256 and size
├── extera-plugins.json              # ExteraGram catalog index (updated on release)
├── LICENSE                          # Custom non-commercial license
├── README.md                        # English
├── README.ru.md                     # Russian
└── README.fa.md                     # Persian
```

فایل‌های تولیدشده مانند `dist/`، فایل‌های `.pyc` و کش‌های محلی ElyxBuilder توسط Git نادیده گرفته می‌شوند.

## 🤝 مشارکت

هر نوع مشارکتی خوشایند است: گزارش باگ، ترجمه یا تغییر در کد.

### گزارش باگ یا پیشنهاد قابلیت

یک [issue](https://github.com/hesCalledAJ/MusicPlus/issues) باز کنید و این موارد را بنویسید:

- انتظار شما چه بود و در عمل چه اتفاقی افتاد؛
- نسخهٔ exteraGram و نسخهٔ Music +‎ خود؛
- مراحل بازتولید مشکل و در صورت نیاز یک اسکرین‌شات.

### افزودن یا اصلاح ترجمه

1. مخزن را Fork کنید.
2. فایل زبان خود را در `MusicPlus/strings/` ویرایش کنید (`strings_en.yml`، `strings_fa.yml` یا `strings_ru.yml`). برای زبان جدید، `strings_en.yml` را کپی و ترجمه کنید.
3. یک Pull Request باز کنید.

### ارسال تغییر در کد

1. مخزن را Fork کنید و یک شاخه (branch) بسازید.
2. تغییرات خود را در `MusicPlus/` اعمال کنید.
3. پروژه را به‌صورت محلی بسازید (بخش «برای توسعه‌دهندگان») و در exteraGram آزمایش کنید.
4. یک Pull Request باز کنید و توضیح دهید چه چیزی را و چرا تغییر داده‌اید.

لطفاً در Pull Request مقدار `version` در `MusicPlus/metainfo.yml` را تغییر ندهید و `extera-plugins.json` را ویرایش نکنید. این‌ها هنگام انتشار نسخهٔ جدید به‌روز می‌شوند.

## 🧩 برای توسعه‌دهندگان

### ساخت محلی

```bash
python -m pip install pyyaml
python scripts/build_elyx.py
```

این دستور نحو پایتون را بررسی می‌کند و فایل `dist/MusicPlus-vX.Y.elyx` را می‌سازد. این فایل را مثل «روش ب» نصب کنید.

### انتشار نسخهٔ جدید (برای نگهدارندگان)

1. مقدار `version` را در `MusicPlus/metainfo.yml` به‌روز کنید و push کنید.
2. یک GitHub Release با تگ متناسب و پیشوند `v` بسازید (نسخهٔ `1.6` ← تگ `v1.6`).

بقیهٔ کار را workflow با نام `release.yml` انجام می‌دهد: فایل `.elyx` را می‌سازد، به Release پیوست می‌کند و `extera-plugins.json` را با نشانی دانلود، SHA-256 و حجم فایل به‌روز می‌کند.

برای ساخت‌های کامپایل‌شده، [مستندات رسمی ElyxBuilder](https://plugins.exteragram.app/docs/elyx/elyxbuilder) را ببینید.
